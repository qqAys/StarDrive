## US-11 文件行预览按钮（本地部分通过）

用临时账号及隔离文件目录，在非批量模式点击和轻触文件行的“预览文件”按钮，确认打开对应文件的既有预览，行选择保持原状且不触发下载。用 Tab 聚焦按钮后分别以 Enter、空格激活。目录和批量模式不显示按钮。用移动视口重复触屏流程。
