# 用户场景验证

以下用例用于验证 [路线图](ROADMAP.md) 和 [生产就绪检查](PRODUCTION_READINESS.md)。执行时记录提交、环境、命令、结果与待验范围。服务层、浏览器、真实服务和容器分别留证。

| 场景 | 样本与验收 |
| --- | --- |
| US-01 新用户 | 空目录启动，打开登录页，安全取得初始凭据并进入 Console。重启保留已有账号。 |
| US-02 普通用户 | 用临时账户登录并配置 Service URL，上传和下载文本并核对字节。第二个账户看不到该文件，也无法打开 Console。 |
| US-03 多选下载 | 勾选两个文件和一个目录，打开归档并核对条目和内容。删除其中一个源后重试，检查错误反馈。 |
| US-04 分享接收者 | 用独立浏览器会话验证访问码、路径范围、过期和撤销。授权回归与异常复现通过私有渠道留证。 |
| US-05 高级用户 | 指定独立数据目录启动，确认日志、SQLite 和本地存储落在预期位置。另用专用 OSS 测试前缀验证档案切换。 |
| US-06 运维人员 | 用空库、损坏样本和历史样本验证启动、恢复及重启。分别记录 HTTP 存活、登录、数据库版本、文件摘要。 |
| US-07 上传中断 | 用临时目录模拟覆盖中断和取消，校验旧内容和临时文件清理。 |
| US-08 开发者 | 按 AGENTS.md 运行锁定安装、格式、测试、翻译和工作流校验。 |
| US-09 贡献者 | 使用 PR 模板记录可复现证据，检查普通 PR 能运行无凭据的 Quality 门禁。 |

使用 [运维指南](OPERATIONS.md) 启动隔离实例。需要预置账户时只写临时库，并单独标记首登用例状态。真实 OSS/SMTP 和 Docker 冒烟应记录服务范围及对应回执。

## US-10 当前目录名称过滤（待执行）

使用临时账号与隔离样本目录，在 `/home/` 准备超过 50 个条目，包含 `Report.TXT`、`中文资料` 文件夹及 `a[1]%.txt`。分别输入 `rEpOrT`、`资料` 和 `[1]%`，确认仅匹配当前目录原始名称。输入不存在的片段时显示空态，清空恢复全部条目。

在后续分页先多选，再输入片段，确认页码回到首页、隐藏项退出选择，批量回调只收到保留项。测试上下键移动、零结果时 Enter，以及输入框编辑时 Backspace、空格和 Enter。打开匹配项详情、关闭详情并清空，确认列表恢复。进入子目录或返回父目录后过滤为空，原搜索按钮仍按当前目录及子目录范围搜索。

分别以本地目录和 OSS 元数据桩运行回归，真实 OSS 与浏览器验收分别留证。本轮新增回归用例尚未执行，不能据此标记场景通过。

## US-11 当前目录类型筛选（待执行）

在隔离目录准备 60 个文件及一个文件夹，翻到后续分页并多选，依次切换全部、仅文件、仅文件夹，确认计数为 61、60、1，页码回首页且旧选择清空。组合名称条件检查大小写和中文，重置后恢复完整列表。空目录显示无文件，有条目但无匹配时显示重置提示。

在排序和翻页后用方向键、Enter、Space 及信息按钮检查目标属于可见结果。无匹配时上述键安全返回。进入子目录、返回父目录后恢复全部类型及空名称。在窄屏确认标签、计数和重置可访问。元数据桩分别覆盖本地和 OSS 路径，筛选不得新增存储读取。运行器测试、浏览器、真实 OSS 与容器结果分别留证。
