# 生产就绪检查

**当前结论为开发预览。** 首次安装、数据保护与依赖分诊仍阻断生产验收。

| 门槛 | 当前状态 | 证据与验收方法 | 风险及剩余工作 |
| --- | --- | --- | --- |
| 首次安装 | 本地候选已验证 | 空目录启动，浏览器首次登录、修改初始凭据并上传下载样本 | 已通过本地首登、拒绝绕过及重启验证。容器和完整安装验收待验。AUD-02 |
| 核心文件流程 | 部分实现 | 两账户上传、目录、预览、下载、覆盖中断、混合归档、删除恢复 | 单文件冒烟与边界测试仍需持续覆盖。AUD-04/06 |
| 授权隔离 | 有阻断项 | 验证所有公开端点、页面回调、过期与撤销、存储切换、账号停用 | SD-01 和 SD-08 的授权边界验收独立跟踪 |
| 依赖与输入 | 有阻断项 | OSV 去重与可达性，容器 OS 扫描，危险格式与资源预算 | 告警已采集，修复版兼容与残余风险待验。AUD-03/09 |
| 配额、限流与故障 | 部分实现 | 并发上传、限额、网络中断、重复操作、取消和故障注入 | 并发配额、归档和 OSS 故障回归待验。AUD-06/09 |
| 就绪与日志 | 提供存活探针 | 访问 `/api/healthz` 并独立验证初始化和登录 | 就绪探针与失败诊断由 SD-07 跟踪 |
| 自动化测试 | 本地门禁可运行 | 锁定依赖、Black、pytest、Babel、actionlint、容器 Smoke 和真实外部测试 | 当前测试以单元和服务层为主。需为关键浏览器流程建立可重复门禁 |
| 镜像与部署 | 已配置，容器待验 | 独立卷构建、初始运行、重启、健康和普通用户写卷 | 评估非 root、固定镜像及网络暴露 |
| 升级与回滚 | 有阻断项 | 真实历史 schema 和文件布局复制升级，校验行数、文件摘要、回滚恢复 | 当前旧库识别依赖实时模型。AUD-05 |
| 文档与支持 | 部分实现 | 由新手照 README 走到首次登录和下载，贡献者从新分支跑通门禁 | 已补充路径、配置、首登和本机恢复说明。容器首装待验 |
| 版本发布 | 仅构建脚本 | RC 构建和安装验证、变更摘要、签署审批、回滚演练 | 公共 GitHub Releases 接口没有可用的 latest release，正式发布由人批准 |

发布前在隔离环境记录基准提交、镜像标签及摘要、数据库迁移前后版本、备份恢复结果、关键场景结果和批准人。P0 必须关闭并有复测证据。单机阶段优先建设结构化日志、就绪探针、容量监控与故障手册。分布式追踪、跨区容灾和数据库集群在当前部署边界内不适用。
