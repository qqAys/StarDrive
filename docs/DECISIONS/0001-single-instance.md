# ADR-0001 保持单实例交付边界

- 日期 2026-11-06
- 状态 本轮维护基线，未来如需改变由维护者审批

StarDrive 的第一目标是让个人和小团队可靠完成上传、预览、分享和恢复。NiceGUI 会话及回调、当前存储档案和本地 SQLite 已有明确的单实例运行路径。继续采用 SQLite 与单实例，把有限维护资源用于边界验证、数据恢复和简单部署。

保持单一活跃后端，切换档案等同切换可见文件空间。稳定前先补齐历史链接和已打开页面的切换语义。新增后端须通过同一套契约测试。现有下载与分享路径优先修复，独立的传输集群、通用插件系统与多副本需要产品证据、兼容方案和人工批准。
