# 部署与排障

StarDrive 当前适用于隔离试用。运行和发布门槛见 [生产就绪](PRODUCTION_READINESS.md)。

## 隔离启动

从仓库根目录运行。指定单独的数据目录、回环地址和端口。使用文件或本机环境保存稳定密钥，测试结束后保留测试记录并按需清理临时目录。

```sh
uv sync --locked
uv run --locked pybabel compile -d app/locales
STARDIVE_APP_DATA_DIR="$(mktemp -d)" \
STARDRIVE_APP_SECRET="$(openssl rand -hex 32)" \
STARDRIVE_APP_HOST=127.0.0.1 STARDRIVE_APP_PORT=8080 \
uv run --locked -m app.main
```

浏览器打开 `http://127.0.0.1:8080/login/`。首登验收见 [生产就绪检查](PRODUCTION_READINESS.md)。已有可用测试账户时，上传一个小文本、双击文件名下载并比较内容。站内下载使用同源 `/api/` 地址，无需设置 `Service URL`；对外分享前需在 Console → Overview 设置完整地址。

本地构建使用 `docker compose -f docker-compose.build.yml up --build`，默认只映射本机回环。预构建 Compose 使用 `qqays/stardrive:latest` 并对所有接口映射，开始前检查镜像标签和端口绑定。单实例代理需要 HTTPS 和 WebSocket，设置符合样本大小的上传请求限制。每个实例使用独立持久化卷。

## 首次管理员登录

空库不再自动创建默认账号或输出临时密码。部署者先生成独立随机凭据（推荐 `openssl rand -hex 32`），
通过进程环境、`.env` 或容器环境注入 `STARDRIVE_APP_SETUP_TOKEN`，至少 32 字符，勿与应用密钥复用。
无需交互终端。打开 `/login/` 后进入 `/login/setup/`，输入安装凭据、自选邮箱、密码及确认密码，
创建后回到登录页。密码沿用现有规则：至少 8 字符，包含大小写字母、数字和特殊字符，最多 72 UTF-8 字节。
安装凭据不放在 URL 中，不应分享、录屏或写入日志。缺失或过短时页面只显示配置指引，普通注册也关闭。
首装通过同源 POST 和有时限的 CSRF 校验提交；失败后重新载入页面再试。反向代理须保留原始 Host，
并仅对可信代理启用转发协议处理，使应用识别的协议与浏览器一致；远程访问使用 HTTPS。

账号与完成标记在 SQLite 同一事务写入，失败回滚后可重试。完成后移除安装凭据并重启。
标记与账号历史共同关闭首装；停用、软删除及待改密账号都不能重开安装。不要删除完成标记来重置实例。
已有实例保留账号、密码和会话语义。旧临时密码登录仍需浏览器改密，改密前不能换取 API 令牌。

忘记管理员密码或旧安装临时密码丢失时，停止服务并备份数据。用运行服务的账号、配置及数据目录
在私有交互终端执行下列命令。容器部署应在已停止原服务的情况下，使用同版本镜像、同一数据卷
和交互终端运行该模块。

```sh
uv run --locked -m app.recover_initial_admin
```

命令仅重置 `STARDRIVE_APP_INIT_USER` 指定的现有启用管理员（浏览器自选邮箱后，恢复前须将此配置设为该邮箱），替换密码并撤销旧会话与邮件重置链接，
一次性输出新临时密码。随后启动服务，在浏览器完成强制改密。回退应用版本时使用配套的升级前备份。
含待改密账号的数据库会拒绝降级，以免旧版本接受仍然有效的临时密码。

## 常用配置

源码运行从进程环境及当前目录的 `.env` 读取配置。Compose 从项目 `.env` 插值，仅传递 `environment` 中声明的项目。修改额外变量需显式传给容器。

| 配置 | 默认与说明 |
| --- | --- |
| `STARDRIVE_APP_SECRET` | 必填。生成稳定随机密钥，避免示例值。旧名 `APP_SECRET` 仍兼容。用于会话、链接签名及 OSS 凭据解密 |
| `STARDIVE_APP_DATA_DIR` | 默认项目根下 `app_data`。当前运行时从进程环境读取，可指定绝对路径或项目根相对路径 |
| `STARDRIVE_APP_HOST` / `STARDRIVE_APP_PORT` | 默认 `0.0.0.0` / `8080`。本机测试使用 `127.0.0.1` |
| `STARDRIVE_APP_SETUP_TOKEN` | 空实例一次性安装凭据，至少 32 字符，推荐独立随机 64 位十六进制值；完成后可移除。Compose 已透传该变量 |
| `STARDRIVE_APP_INIT_USER` | 离线恢复目标邮箱，默认 `admin@stardrive.abc`，新实例应设置为自选管理员邮箱 |
| `STARDRIVE_APP_ALLOW_REGISTRATION` | 默认开启。只用于初始化注册策略，之后由 Console 管理 |
| `STARDRIVE_APP_DEFAULT_USER_QUOTA_BYTES` | 新普通用户默认 10 GiB |
| `STARDRIVE_APP_DEFAULT_LANGUAGE` / `STARDRIVE_LOG_LEVEL` | 默认 en-US / INFO |
| `STARDRIVE_LOCAL_DB_DSN` | 默认数据目录中的文件型 SQLite。覆盖后备份必须包含实际库文件及其同目录关联文件 |
| `STARDRIVE_SMTP_HOST/PORT/SENDER` | 重置邮件的服务器、端口与发件人。端口默认 587；用户名和密码可选。按需检查 `STARDRIVE_SMTP_USE_TLS` |
| `STARDRIVE_PASSWORD_RESET_BASE_URL` | 设置用户可访问的 HTTPS 绝对地址。未设置时尝试使用 Console 的 Service URL |
| `STARDRIVE_DEBUG` | 默认关闭。调试界面和错误输出只适用于隔离环境 |

OSS 连接测试检查 Bucket 信息。对象读写、复制、删除和分段上传需要额外权限。使用范围受限的测试前缀验证。切换存储时先记录活跃档案和路径，完成备份并关闭旧页面。切换不会搬迁或合并文件。

## 本地上传与故障恢复

本地上传将内容流式写入目标同目录的 `.stardrive-upload-<随机标识>.tmp`，完整接收并关闭后原子替换目标。接收、写入、关闭或替换失败及任务取消时，已有目标保持原内容，新目标不留下半成品；后台 I/O 完成后关闭并删除本次暂存文件。浏览器的取消按钮不能撤销已经成功替换的文件。

覆盖保留原文件权限位，新文件沿用 `0666 & ~umask`；需要父目录创建、删除及替换权限，原文件仍须可写。替换会创建新 inode，已有硬链接和打开的读取句柄仍指向旧内容；所有者、ACL、扩展属性不承诺保留。用户根隔离及 OSS 上传接口保持原有行为。

上传期间需要同时容纳旧文件与新暂存内容。同一路径并发上传各用独立暂存，最后成功替换者生效，最终文件来自一次完整上传。本阶段不提供并发配额预留。原子可见性不等于断电持久性：未执行文件及目录 fsync，系统崩溃后的结果由文件系统决定。

进程强制退出或系统崩溃可能留下隐藏暂存文件，仍会占用磁盘，应用不自动删除。停止服务并确认无上传后，仅清理通过专用命名及运维记录确认归属的暂存文件，勿删除目标或其他隐藏文件。回退时先停止进行中的上传，再回退代码；已成功替换的文件无需格式迁移，可直接读取。

## 备份与恢复

1. 停止应用并确认无写入。记录应用版本或镜像摘要、数据库实际位置、活跃档案和 OSS 前缀。
2. 对 `app_data` 和单独配置的数据库目录做一致性备份，包含本地文件、SQLite、NiceGUI 状态。密钥在私有存储单独备份。OSS 对象用独立的桶版本或备份策略，核对可恢复性。
3. 先在独立目录恢复副本，以旧版本和对应密钥启动。核对数据库版本、管理员登录、档案、文件数量和抽样摘要，再尝试升级。验证失败时保留日志及原始副本。
4. 回滚使用旧版本和完整的升级前备份。避免对唯一数据副本执行降级。历史无版本库的识别仍有阻断，详见 [AUD-05](PROJECT_AUDIT.md#审计结果)。

检查当前实际数据库时使用 `sqlite3 -readonly <数据库路径> 'SELECT version_num FROM alembic_version;'`。裸 `alembic` 命令读取 `alembic.ini` 的默认数据库地址，和自定义运行配置可能不同。

## 常见故障

| 现象 | 检查与处理 |
| --- | --- |
| `healthz` 200，登录页不可用 | 存活探针只检查 HTTP。查看进程日志，检查密钥、数据目录权限与 SQLite 结构 |
| 首装页面提示配置或提交失败 | 检查安装凭据及长度、代理 Host/协议，重新载入表单；旧账号密码丢失时停服备份并本机恢复 |
| 分享链接无法创建 | 确认 Console 的 Service URL 为收件人可访问的站点地址 |
| OSS 启用后列表变空 | 核对用户、档案、Bucket 和前缀，原后端数据需要切回查看 |
| Office 预览提示缺依赖 | 安装 LibreOffice 与所需字体或使用包含它的容器构建，复测同一示例 |
| 密码邮件失败或链接只有相对路径 | 检查 SMTP TLS、发件人权限与绝对回调地址，使用专用测试收件人复测 |
| 上传后表格无刷新或 WebSocket 断开 | 检查代理升级头、请求大小和超时，使用回环测试隔离代理影响 |

当前 HTTP 接口为应用内部契约。健康接口可无凭据探测，返回版本与状态。登录、注册、重置、签名下载和预览为应用功能入口。稳定第三方文件 API 尚未发布。

## 私有归档下载

文件列表多选下载通过私有 HTTP 入口生成 `tar.gz`，文件与目录共用用户根隔离。当前登录会话须有效，且账号须与下载记录所有者一致。响应开始前检查选中源，生成中源消失或读取失败会终止传输。客户端断开时停止压缩并关闭当前读取流。压缩通道最多缓存 8 个 64 KiB 数据块，底层存储正在进行的同步读取仍需等待其返回。

新多选记录以 `MIXED` 类型标记，`path` 保存 `{"version": 1, "paths": [...]}`，普通文件与目录的路径保持字面值。无需 schema 迁移。降级前停止服务并备份 SQLite 数据库，再在数据库副本中隔离新增的 `MIXED` 下载记录并验证旧版本。恢复时使用完整备份及匹配版本。回滚后可重新创建旧格式的单文件或目录链接。本阶段仅改变归档条目去重，无新增持久化格式。回退本阶段后旧下载记录仍可读取，但重复选择可能再次产生重复归档条目。

### 跨后端归档规则与验证

本地和 OSS 的相同规范化路径（包括 `./` 和末尾斜杠）在归档中只出现一次。目录与子项重叠选择时仍保留完整目录树，子项先选中时沿用其首次出现的位置。路径前缀相同的相邻名称分别保留。归档保留 Unicode、零字节文件和空目录，OSS 列举须消费全部分页。

归档不是存储快照。开始前检查所有选择，递归遍历时重新取得元数据和读取内容。源消失、短读、列举或网络读取失败均终止传输。相同长度的内容替换以及遍历后新增的文件无法保证检测，归档期间请避免修改源。断开后的同步网络读取仍受底层 SDK 超时约束。

`tests/test_archive_backends.py` 使用同一合成目录树验证两驱动的名称、目录项、内容摘要、分页、去重与故障清理。运行 `uv run --locked pytest tests/test_archive_backends.py` 可复跑。

#### 真实 OSS 归档验收

1. 启动使用临时 SQLite 和独立数据目录的测试实例。配置专用 OSS Bucket 或隔离的测试前缀，并使用专用测试账号。先运行现有的 `uv run --locked pytest tests/integration/test_aliyun_oss_live.py` 验证配置、对象读写和清理。该用例需要专用测试环境变量，缺少配置时会跳过。
2. 在该账号下创建 `archive/空目录/`，上传文本文件 `archive/资料.txt` 和零字节文件 `archive/sub/zero`。记录源文件的 SHA-256。
3. 在文件列表多选 `archive` 和另一个合成文件并下载。用 `tar -tzf` 核对两项都在归档里，目录树中保留 Unicode、空目录和零字节文件，每个路径只出现一次。用 `tar -xOf` 读取归档内的文件并比较 SHA-256。重叠选择、分页和网络故障由上述自动化用例覆盖。
4. 保存归档条目和摘要比对结果，清理测试账号创建的合成文件和目录。真实 OSS 归档验收待执行。

### OSS 批量删除确认

每批最多 1000 项，使用详细响应核对成功对象。缺少确认会停止后续批次并报告失败，已删除对象不会恢复。移动在复制完成后才删除源，删除失败时保留目标副本。请刷新并核对源与目标内容后再决定重试，应用不会自动重试。无数据库迁移，回退代码前应记录未完成操作并核对两端内容。真实 OSS 契约仍待验证。

### 整理操作失败后的核对

删除、移动或重命名失败可能已经完成部分操作。列表刷新后先核对源位置剩余条目，再打开目标位置核对副本内容。移动复制失败时源仍保留，目标可能只有部分副本；删除阶段失败时保留已复制目标。确认内容完整后再处理剩余源条目，避免直接重复移动。回退界面反馈不需要数据库迁移，仍保留 OSS 删除确认检测。

### 浏览器首装的兼容与回退

本阶段不增加表或列，`app_settings.initial_setup_completed` 与首任管理员原子保存。
升级前按上述流程停服备份，在独立目录恢复副本并迁移，核对原有账号与密码仍可登录。
回退到上一版本时保留整个数据库及完成标记，新管理员使用已有密码哈希和正常登录状态，
无需降级 schema 或删除账号。旧版本不识别首装标记，不能在回退后删除所有账号再启动：
旧代码会自动建临时管理员。重新升级后标记仍关闭首装。
若必须退回安装前状态，恢复完整的升级前备份，并使用匹配版本；安装后新增账号及文件应另行保全。
`tests/test_first_run_setup.py` 覆盖合成库备份恢复、事务故障重试、并发与旧账号兼容；
真实浏览器、容器安装及旧版本应用实际登录另行验收，不能以服务层或哈希格式测试代替。

## S3 独立驱动

本阶段仅允许在隔离开发样本中显式构造 `S3Storage(S3Config(...), user_id)`，
未注册为可激活档案，不改数据库或现有 Local/OSS 文件。凭据必须显式提供，
不使用主机默认凭据链。SDK 使用 path-style、5 秒连接超时、30 秒读取超时及
standard 模式最多 3 次请求尝试。私有端点与管理员探测目的地规则属于下一阶段。

上传以 8 MiB 分段缓冲，零字节及不足一段的文件走 PUT；上传生产者失败、取消或
SDK 请求失败时终止已创建的分段任务。取消等待正在执行的请求退出后清理，不能
强制中断工作线程。终止未确认时必须在隔离服务核查未完成的 multipart；进程崩溃
无法执行清理，应在服务端设置未完成分段的生命周期回收规则。
提交完成请求后断线存在结果不确定性，重试前先核对对象摘要。下载流不在输出
部分字节后自动重试，读取失败需重新发起下载；流关闭会关闭响应体。

目录移动先复制全部对象，再删除源；复制失败保留源，目标可能含部分副本。
移动在复制前拒绝相同路径、源的祖先及子目录目标，避免源与目标键重叠。
逐批删除缺少确认或返回错误时停止，保留目标副本，核对源与目标后再重试。
单对象复制超过 5 GiB 明确拒绝，不进入源删除；本阶段未实现 multipart copy。
操作不提供多对象事务或并发写入快照，移动时避免修改源和目标。

回退时移除独立驱动和 boto3 依赖即可，原档案与对象不变；用合成 Local/OSS
样本重新验证下载与归档。无数据库降级或数据迁移步骤。真实服务与回退执行待验。
本阶段测试使用内存协议客户端；SDK 参数测试不等于真实服务契约验收。
